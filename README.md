# Proyecto de Web Scraping Pokémon

Proyecto académico de extracción, limpieza, análisis y visualización
de datos utilizando BeautifulSoup, Pandas y Streamlit.

## Fuente de los datos

Los datos se extraen de:

https://scrapeme.live/product-category/pokemon/

Es una página creada para practicar web scraping.

## Datos extraídos

- Nombre
- Precio
- Stock
- SKU
- Categoría
- Etiquetas
- Descripción
- Peso
- Imagen
- URL
- Fecha de extracción

## Tecnologías utilizadas

- Python
- Requests
- BeautifulSoup
- Pandas
- Streamlit
- Plotly
